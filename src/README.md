# Reusable Implementation

Put reusable method, framework adapters, metrics, and evaluation components here once the team chooses a question and implementation stack. Keep experiment-specific orchestration in [experiments](../experiments/README.md) and settings in [configs](../configs/README.md). Add the language environment and dependency lock with the first implementation; no robotics framework is preselected.

Borrowed implementations retain licenses and source references. A paper/code audit belongs in the knowledge base, not as an undocumented modification to upstream code.
