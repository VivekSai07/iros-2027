# Task Logs

Use a unique `<date>-<owner>-<topic>.md` per task with the [task template](../docs/templates.md#task-record). Record useful factual state, tool versions, commands, verification, blockers, costs where observable, and next steps. Do not record secrets, participant identities, unredacted conversations, or private reasoning.

Parallel workers maintain separate task files; a coordinator updates shared research indexes. The append-only scientific decisions remain in [the decision log](../knowledge/01-decision-log.md), and literature passes in [the iteration log](../knowledge/07-iteration-log.md).
