# Experiments

Use one directory per experiment ID with a protocol, runnable entry point, and analysis command. Shared implementation belongs in [src](../src/README.md); records belong in [results](../results/README.md).

The existing [G4 power simulation](g4-fluency-metrics-validity/power.py) and [historical output](g4-fluency-metrics-validity/power_results.txt) are preserved. They are prior exploratory work, not a newly validated study design or approval to collect participant data. The script and its environment have not been rerun by repository setup.

Start with the [experiment protocol](../docs/templates.md#experiment-protocol) and follow the [workflow](../docs/workflows.md#7-experiments-and-results).
