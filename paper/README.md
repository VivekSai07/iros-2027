# Paper And Submission

Manuscript source, citation database, reviewed figures, supplementary text, and submission checklists live here. Do not adopt a paper title or contribution before the team chooses the question. The existing [candidate story](../knowledge/06-paper-story.md) remains provisional.

## Write throughout the project

Before the conference template is available, draft portable Markdown in this directory:

- [Outline](outline.md) holds the current story and explicit unknowns.
- [Sections](sections/README.md) holds evidence-backed prose that can later move into LaTeX.
- Every quantitative claim links to a [run record](../results/README.md); every literature claim links to a reviewed source note or carries its evidence status.

The three-person team writes in the same directory, but one person owns a section in a given milestone. Others contribute through branch drafts, comments, or reviewed suggestions rather than simultaneous edits to the same file. See the current [team board](../TODO.md) and [research sprint plan](../docs/plans/2026-11-01-research-sprint-coordination.md).

Add the verified conference template and build instructions only after the official requirements are available. Generated builds belong in ignored `build/`. Before submission check authorship, anonymization, ethics, licenses, and required tool-use disclosures; the human team approves and submits.
