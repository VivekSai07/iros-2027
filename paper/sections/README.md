# Shared Markdown Sections

Use this directory for prose that is ready to transfer into a future verified LaTeX template. Create a section file only when it contains reviewed content; avoid empty speculative manuscript files.

## Ownership rule

At each milestone, the team assigns one editor to each active section. Other teammates contribute on their own branches or as comments, then the section editor incorporates reviewed material. Record the editor and milestone at the top of every section file.

## Required claim discipline

- Literature claim: source URL/identifier plus `[V]`, `[S]`, or `[U]` evidence status.
- Experimental claim: link to a completed run record, analysis command, and figure/table source.
- Proposal: label as proposed; never phrase it as an observed result.
- Citation or result not yet verified: leave it out of polished prose and keep the uncertainty in `knowledge/`.

Suggested future files are `01-introduction.md`, `02-related-work.md`, `03-method.md`, `04-evaluation.md`, `05-results.md`, and `06-discussion.md`.
